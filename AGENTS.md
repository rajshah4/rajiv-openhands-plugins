# Rajiv OpenHands Plugins Repository

This repository hosts a personal plugin marketplace for OpenHands.

## Purpose

- keep a small set of reusable, demo-friendly plugins in one marketplace
- mix copied public samples with Rajiv-specific operator and engineering helpers
- optimize for plugins that are easy to show in `/plugins` and easy to launch in a conversation

## Current plugin mix

- `city-weather`
- `magic-test`
- `repo-primer`
- `incident-brief`
- `release-ready`
